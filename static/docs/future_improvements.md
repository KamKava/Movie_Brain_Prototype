# Movie Brain — Future Improvements

Possible future improvements include:

* Replace CSV storage with SQLite or PostgreSQL.
* Add an external movie API to automatically retrieve movie information.
* Add movie posters, cast and descriptions.
* Improve the recommendation system using viewing history and preferences.
* Improve the Android interface and release packaging.
* Separate the backend into an API if the project grows.

These improvements would allow Movie Brain to move from a small personal application towards a more scalable system.
